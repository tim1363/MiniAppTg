# 🚀 Multi Telegram Manager - Quick Start Guide

## Instant Setup (2 minutes)

### 📦 Ready-to-Use Version
1. **Download** `MultiTelegram.exe` from releases
2. **Double-click** to run (no installation needed!)
3. **Click** "➕ Create New Instance"
4. **Login** to your first Telegram account
5. **Repeat** for more accounts

### ✨ Key Features
- **Unlimited Accounts** - Create as many as you need
- **Auto-Save Sessions** - Never lose your logins
- **System Tray** - Runs in background
- **Smart Management** - Show/hide/organize instances

### 🎯 Perfect For
- Social media managers
- Customer support teams
- Developers testing
- Power users with multiple accounts

### 🔥 Pro Tips
- `Ctrl+N` = New instance
- `Ctrl+R` = Restore saved
- Right-click = Instance menu
- Double-click = Show/Hide

### 🛠️ Build From Source (Developers)
```bash
# Requirements: .NET 6.0 SDK + Windows 10/11
git clone https://github.com/tim1363/MiniAppTg
cd MiniAppTg
build_release.bat
```
