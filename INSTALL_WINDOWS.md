# 🪟 Установка Multi Telegram на Windows

## 🎯 Быстрый старт (Рекомендуется)

### Вариант 1: Готовый исполняемый файл
1. Скачайте **MultiTelegram.exe** из раздела Releases
2. Поместите файл в любую папку (например, `C:\MultiTelegram\`)
3. Запустите **MultiTelegram.exe** от имени администратора (первый раз)
4. При появлении Windows Defender SmartScreen нажмите "Подробнее" → "Выполнить в любом случае"
5. Готово! Приложение запустится

## 🛠️ Сборка из исходного кода

### Требования:
- **Windows 10/11** (x64)
- **.NET 6.0 SDK** или выше
- **Visual Studio 2022** (опционально, для удобства)

### Шаг 1: Установка .NET SDK
1. Перейдите на https://dotnet.microsoft.com/download
2. Скачайте **.NET 6.0 SDK** (или новее)
3. Установите, перезагрузите компьютер

### Шаг 2: Проверка установки
Откройте командную строку и выполните:
```cmd
dotnet --version
```
Должно показать версию .NET (например, `6.0.xxx`)

### Шаг 3: Клонирование и сборка
```cmd
git clone https://github.com/tim1363/MiniAppTg
cd MiniAppTg
```

#### Автоматическая сборка:
```cmd
build.bat
```

#### Ручная сборка:
```cmd
dotnet restore MultiTelegram.sln
dotnet build MultiTelegram.sln --configuration Release
dotnet publish MultiTelegram -c Release -r win-x64 --self-contained true
```

### Шаг 4: Запуск
Перейдите в папку с готовым файлом:
```cmd
cd MultiTelegram\bin\Release\net6.0-windows\win-x64\publish\
MultiTelegram.exe
```

## 🔧 Возможные проблемы и решения

### ❌ "dotnet не является внутренней или внешней командой"
**Решение:** Установите .NET SDK заново, убедитесь что PATH прописан

### ❌ "Windows защитил ваш компьютер"
**Решение:** Нажмите "Подробнее" → "Выполнить в любом случае"

### ❌ "Приложение не может запуститься (0xc0000135)"
**Решение:** Установите .NET 6.0 Runtime: https://dotnet.microsoft.com/download/dotnet/6.0

### ❌ "WebView2 не найден"
**Решение:** 
1. Обновите Windows до последней версии
2. Или скачайте WebView2 Runtime: https://developer.microsoft.com/microsoft-edge/webview2/

### ❌ Высокое потребление памяти
**Решение:** Используйте не более 5-7 экземпляров одновременно

### ❌ Telegram не загружается в экземпляре
**Решение:** 
1. Проверьте подключение к интернету
2. Временно отключите антивирус
3. Запустите от имени администратора

## 🔒 Безопасность

### Антивирусы
Некоторые антивирусы могут блокировать приложение. Добавьте в исключения:
- **Windows Defender:** Параметры → Обновление и безопасность → Безопасность Windows → Управление контролируемым доступом к папкам
- **Kaspersky:** Настройки → Дополнительно → Угрозы и исключения → Исключения
- **Avast:** Настройки → Общие → Исключения

### Права доступа
Приложение может потребовать права администратора для:
- Создания временных папок
- Регистрации WebView2 компонентов
- Доступа к сетевым настройкам

## 📊 Системные требования

### Минимальные:
- **ОС:** Windows 10 (1903) или Windows 11
- **ЦП:** Intel Core i3 или AMD аналог
- **ОЗУ:** 4 GB (для 3-4 экземпляров)
- **Место:** 500 MB свободного места

### Рекомендуемые:
- **ОС:** Windows 11 (последняя версия)
- **ЦП:** Intel Core i5 или AMD Ryzen 5
- **ОЗУ:** 8+ GB (для 5+ экземпляров)
- **Место:** 2 GB свободного места

## 🚀 Оптимизация производительности

### Для максимальной производительности:
1. **Закройте ненужные программы** перед запуском множественных экземпляров
2. **Используйте SSD** для лучшей скорости загрузки
3. **16+ GB RAM** для комфортной работы с 10+ экземплярами
4. **Стабильное интернет-соединение** (50+ Мбит/с)

### Мониторинг ресурсов:
- Открывайте **Диспетчер задач** (Ctrl+Shift+Esc)
- Следите за использованием ЦП и памяти
- При достижении 80%+ ОЗУ закройте лишние экземпляры

## 🎯 Часто задаваемые вопросы

**Q: Сколько экземпляров можно запустить?**  
A: Теоретически неограниченно, практически зависит от RAM. Рекомендуется 3-7 для обычного ПК.

**Q: Нужен ли VPN?**  
A: Не обязательно, но может помочь для дополнительной анонимности.

**Q: Сохраняются ли данные между запусками?**  
A: Да, каждый экземпляр сохраняет свои данные отдельно.

**Q: Можно ли запускать на Windows 7?**  
A: Нет, требуется Windows 10 или новее из-за WebView2.
