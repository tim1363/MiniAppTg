# Руководство по использованию Multi Telegram

## 🎯 Основные сценарии использования

### 1. Для бизнеса
- Управление несколькими корпоративными аккаунтами
- Разделение личных и рабочих чатов
- Команда поддержки с разными ролями

### 2. Для маркетинга
- Управление группами и каналами
- A/B тестирование контента
- Мониторинг конкурентов

### 3. Для разработчиков
- Тестирование ботов
- Отладка интеграций
- Работа с разными API ключами

## 🔧 Решение специфических задач

### Автоматический вход в аккаунты

Можно расширить код для сохранения данных входа:

```javascript
// В main.js добавить сохранение данных сессии
ses.webRequest.onBeforeSendHeaders((details, callback) => {
    // Добавить логику сохранения куки
    details.requestHeaders['User-Agent'] = randomUA;
    callback({ requestHeaders: details.requestHeaders });
});
```

### Группировка экземпляров

Добавить теги или категории для экземпляров:

```javascript
// Расширение объекта экземпляра
this.windows.set(instanceId, {
    window: telegramWindow,
    session: ses,
    userAgent: randomUA,
    created: new Date(),
    category: 'work', // или 'personal', 'testing'
    description: 'Описание экземпляра'
});
```

### Настройка прокси

Для каждого экземпляра можно настроить свой прокси:

```javascript
// В createTelegramInstance() добавить:
ses.setProxy({
    proxyRules: 'socks5://your-proxy:port',
    proxyBypassRules: 'localhost'
});
```

## 🚨 Важные предупреждения

### Ограничения Telegram
- Не злоупотребляйте созданием аккаунтов
- Соблюдайте правила использования Telegram
- Используйте только для законных целей

### Производительность
- **Оптимальное количество**: 3-5 экземпляров
- **Максимальное**: не более 10 одновременно
- **Память**: каждый экземпляр ~100-150MB RAM

### Безопасность
- Не передавайте данные между экземплярами
- Используйте VPN при необходимости
- Регулярно очищайте данные сессий
