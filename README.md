# Multi Telegram - Множественные экземпляры Telegram

Приложение для запуска нескольких экземпляров Telegram на одном устройстве с обходом ограничений.

## 🚀 Возможности

- ✅ Запуск неограниченного количества экземпляров Telegram
- ✅ Полная изоляция данных между аккаунтами
- ✅ Обход детекции устройства через уникальные сессии
- ✅ Различные User-Agent для каждого экземпляра
- ✅ Красивый интерфейс управления экземплярами
- ✅ Горячие клавиши для быстрого создания экземпляров
- ✅ Статистика использования ресурсов

## 📋 Требования

- Windows 10/11
- Node.js версии 16 или выше
- Подключение к интернету

## 🔧 Установка

1. **Клонируйте репозиторий или скачайте файлы**
   ```bash
   git clone <ваш-репозиторий>
   cd multi-telegram
   ```

2. **Установите зависимости**
   ```bash
   npm install
   ```

3. **Запустите приложение**
   ```bash
   npm start
   ```

## 🏗️ Сборка исполняемого файла

Для создания .exe файла:

```bash
npm run build
```

Готовое приложение будет в папке `dist/`.

## 🎮 Использование

1. **Запустите приложение** - откроется главное окно управления
2. **Создайте новый экземпляр** - нажмите кнопку "Создать новый экземпляр Telegram"
3. **Войдите в аккаунт** - в открывшемся окне войдите в свой Telegram аккаунт
4. **Повторите для других аккаунтов** - создайте столько экземпляров, сколько нужно

### Горячие клавиши

- `Ctrl+N` - Создать новый экземпляр Telegram
- `Ctrl+Q` - Выйти из приложения
- `F5` - Обновить список экземпляров

## 🔒 Как работает обход ограничений

Приложение использует несколько техник для обхода детекции:

1. **Изолированные сессии** - каждый экземпляр использует отдельную сессию Electron
2. **Уникальные User-Agent** - случайные браузерные идентификаторы
3. **Разные IP-заголовки** - эмуляция разных сетевых подключений
4. **Отдельное хранилище** - изолированные cookies и локальное хранилище

## ⚠️ Важные замечания

- Это приложение предназначено для легального использования
- Каждый экземпляр потребляет ~100MB оперативной памяти
- Рекомендуется не запускать более 10 экземпляров одновременно
- При первом запуске может потребоваться время для загрузки Telegram Web

## 🐛 Решение проблем

### Не запускается экземпляр Telegram
- Проверьте подключение к интернету
- Убедитесь, что web.telegram.org доступен
- Перезапустите приложение

### Высокое потребление памяти
- Закройте неиспользуемые экземпляры
- Перезапустите приложение
- Используйте не более 5-7 экземпляров одновременно

### Ошибки при создании экземпляра
- Проверьте, что Node.js установлен корректно
- Убедитесь, что все зависимости установлены
- Попробуйте запустить от имени администратора
