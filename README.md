# Multi Telegram - Множественные экземпляры Telegram для Windows

**Нативное Windows приложение** для запуска множественных экземпляров Telegram с полным обходом ограничений "один аккаунт на устройство".

## 🚀 Основные возможности

- ✅ **Нативное Windows приложение** (C# WinForms + WebView2)
- ✅ **Полная изоляция** - каждый экземпляр абсолютно независим
- ✅ **Обход детекции устройства** через уникальные сессии и User-Agent
- ✅ **Неограниченное количество** аккаунтов Telegram
- ✅ **Красивый интерфейс** управления экземплярами
- ✅ **Горячие клавиши** (Ctrl+N для создания нового)
- ✅ **Статистика ресурсов** и мониторинг
- ✅ **Контекстное меню** для управления каждым экземпляром

## 📋 Системные требования

- **Windows 10/11** (обязательно)
- **.NET 6.0 Runtime** или выше
- **Microsoft Edge WebView2** (обычно уже установлен)
- **4+ GB RAM** (рекомендуется 8GB для множественных экземпляров)
- **Подключение к интернету**

## 🔧 Установка и запуск

### Вариант 1: Готовый .exe файл (Рекомендуется)
1. Скачайте **MultiTelegram.exe** из Releases
2. Запустите файл от имени администратора (первый раз)
3. Готово! Приложение запустится автоматически

### Вариант 2: Сборка из исходников
1. **Установите Visual Studio 2022** или **Visual Studio Build Tools**
2. **Клонируйте репозиторий:**
   ```bash
   git clone https://github.com/tim1363/MiniAppTg
   cd MiniAppTg
   ```

3. **Соберите проект:**
   ```bash
   dotnet build MultiTelegram.sln --configuration Release
   ```

4. **Запустите:**
   ```bash
   dotnet run --project MultiTelegram
   ```

## 🏗️ Создание исполняемого файла

Для создания standalone .exe файла:

```bash
dotnet publish MultiTelegram -c Release -r win-x64 --self-contained true
```

Готовое приложение будет в папке `MultiTelegram/bin/Release/net6.0-windows/win-x64/publish/`

## 🎮 Использование

1. **Запустите MultiTelegram.exe** - откроется главное окно управления
2. **Нажмите "➕ Создать новый экземпляр Telegram"** 
3. **Войдите в аккаунт** - в новом окне введите номер телефона и код
4. **Повторите для других аккаунтов** - создавайте столько экземпляров, сколько нужно
5. **Управляйте экземплярами** через главное окно или контекстное меню

### 🔥 Горячие клавиши

- `Ctrl+N` - Создать новый экземпляр Telegram  
- **Двойной клик** на экземпляр - показать/скрыть окно
- **Правый клик** на экземпляр - контекстное меню (показать/скрыть/закрыть)

### 📱 Управление экземплярами

- **Показать/Скрыть** - управление видимостью окон
- **Статистика** - количество активных экземпляров и потребление памяти  
- **Автоочистка** - временные файлы удаляются при закрытии экземпляра

## 🔒 Как работает обход ограничений

Приложение использует передовые техники для полного обхода детекции:

1. **Изолированные WebView2 сессии** - каждый экземпляр работает в своей изолированной среде
2. **Уникальные User-Agent** - случайные идентификаторы Chrome/Firefox/Edge  
3. **Отдельные пользовательские папки** - полностью изолированные данные в temp-папках
4. **Случайные IP-заголовки** - эмуляция подключений с разных устройств
5. **Различные настройки браузера** - каждый экземпляр имеет уникальную конфигурацию

## ⚠️ Важные замечания

- Это приложение предназначено для легального использования
- Каждый экземпляр потребляет ~100MB оперативной памяти
- Рекомендуется не запускать более 10 экземпляров одновременно
- При первом запуске может потребоваться время для загрузки Telegram Web

## 🐛 Решение проблем

### Не запускается экземпляр Telegram
- Проверьте подключение к интернету
- Убедитесь, что web.telegram.org доступен
- Перезапустите приложение

### Высокое потребление памяти
- Закройте неиспользуемые экземпляры
- Перезапустите приложение
- Используйте не более 5-7 экземпляров одновременно

### Ошибки при создании экземпляра
- Проверьте, что Node.js установлен корректно
- Убедитесь, что все зависимости установлены
- Попробуйте запустить от имени администратора
